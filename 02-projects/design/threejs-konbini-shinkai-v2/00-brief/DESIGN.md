# DESIGN — Konbini Shinkai v2

> 最高标准。静帧不过审 = 失败重做。默认开场：**雨黄昏**（琥珀斜阳，可切晴阴与时段）。

## 0. 旧版失败对照（禁止重演）
1. 彩色方块货架/商品玩具感
2. 天空噪声贴片、空气透视弱
3. 假湿路 + 灯光无电影光比
4. 四周堆邻店楼群、街区大盘，便利店被淹没

## 2. 天空与大气（主角之一）
- 多层穹顶：zenith/horizon + sakura 带 + 星点（夜）
- fbm 云：受光缘 Amber 高对比、背光冷暗；阴天覆盖升；雨天压暗+高度雾
- 空气透视：远树 / 铁道 / 轻量剪影染蓝紫灰；雾色随天空
- 琥珀 Directional + 克制假丁达尔

## 3. 空间与环境组成
画面主体只有**一栋**便利店。禁止邻店楼群和街区大盘感。

外围走新海诚式自然 + 日常诗意，形成侧翼与纵深层次：
- **樱花树**：暮色 / 雨黄昏下粉白花冠、轻花瓣、微风轻摆；克制，日常诗意，不作幻想自发光或诡谲树冠
- **铁道 / 列车**：中远景轨道从侧翼或店后穿过，一列通勤列车服务构图（可缓缓驶过）；尺度服从便利店，不升级成站场大场景
- 草坡、电线杆 + 弧垂电线、路灯
- 远景若留建筑，只作统一风格的轻量剪影或极低密度辅助
- 天空与大气仍占画面大面积

本店：雨棚有厚度、招牌一条红、落地橱窗反射、自动门金属框；室内货架有厚度隔板、冷柜灯带、收银岛、地砖、顶灯格栅——禁止彩虹方块。

街角湿沥青用 Reflector，倒影需能读到店面与灯箱；人行道 / 路缘、贩卖机、自行车保留生活密度。

镜头：街角建立，大面积天空，便利店 3/4，樱花与铁道在侧翼或后方分层。

## 4. 灯光分层
Sky hemi、Amber key、灯箱/雨棚暖白、冷柜青、路灯暖晕、室内顶灯；ACES+sRGB；bloom 极弱。
